## Retained knowledge affected one task

Both experience summaries correctly captured their original workflow's trim/case/prefix/suffix convention. All four generated summaries were available and remained unverified guidance. Acquisition exited before 24 distinct actor processes loaded immutable snapshots; original source trajectories were absent from those snapshots.

In stable profile B's fresh case, experience applied the saved rule to a new external reference without looking it up. Both controls used the documented lookup. Its invoice passed the private native checker with five calls instead of six. This is a concrete example of useful retained environment knowledge.

The other three stable cases still performed a lookup. In the ambiguous profile B case, experience deferred it until after reconciling the uncertain invoice creation, so it saved no call. Knowledge availability did not reliably remove redundant discovery. Some generated advice was also imperfect: profile A's refresh sentence names the old version even for a version change, while documentation advice for profile B includes reservation steps inappropriate to the unchanged-order goal. Actual actors followed the current task constraints; the summaries themselves were never promoted to verified procedures.

## Refresh safety and task correctness differed

Both changed-version cases in every arm read the exact current policy before annotation and made zero stale-convention write attempts. The version-safety guard passed 2/2 for every condition. Native completion on these cases was only 1/2.

The common failure required normalizing ` ExT-89bc56ae ` to `LM/EXT-89BC56AE/7`. All three actors wrote `LM/EXT-89bc56ae/7`, leaving part of the identifier lowercase, then reported completion. The actual successful write receipt contains that wrong value. This is an exact transformation error after correct policy discovery, not a stale-memory effect or a grading artifact.

Stable cases passed 4/4 in every arm; disclosed consumed legacy regressions passed 2/2. No revised score is substituted for the original result.
